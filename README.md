## Overview

The **Osher Digital RAG Platform** is a proprietary system for building, managing, and deploying Retrieval-Augmented Generation (RAG) agents and knowledge environments.

It is based on a heavily modified fork of the open-source **RAGFlow** project (Apache 2.0).

This version is maintained privately by **Osher Digital Pty Ltd** and is **not distributed or licensed for public use**.
